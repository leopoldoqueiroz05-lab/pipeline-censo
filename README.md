# 📊 Pipeline de Qualidade de Dados - Censo Escolar

Este projeto consiste em um pipeline de dados em Python focado na validação, tratamento e garantia de qualidade de dados (Data Quality) aplicado aos dados do Censo Escolar.

## 🚀 Tecnologias Utilizadas

* **Python 3.x**
* **Pandas** (Tratamento e manipulação de dados)
